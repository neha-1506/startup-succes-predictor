# startup-succes-predictor
Developed a Machine Learning-based Startup Success Predictor to predict whether a startup is likely to succeed or fail. Performed data preprocessing, EDA, feature analysis, and model training using Logistic Regression, Decision Tree, and Random Forest, followed by model evaluation using classification metrics.
# Key work performed:

Collected and analyzed startup data containing business-related features and the target success indicator.

Performed Exploratory Data Analysis (EDA) to understand distributions, relationships, missing values, outliers, and class imbalance.

Cleaned and preprocessed the dataset by handling missing values, removing irrelevant features, encoding categorical variables, and preparing the data for modeling.

Performed feature analysis and correlation checks to identify important variables and reduce unnecessary or highly correlated features.

Split the dataset into training and testing sets to evaluate model performance on unseen data.

Implemented and compared multiple ML algorithms, including Logistic Regression, Decision Tree, and Random Forest.

Evaluated the models using accuracy, precision, recall, F1-score, confusion matrix, and other relevant metrics.

Selected the most suitable model based on its performance and ability to generalize to unseen startup data.

Identified and addressed data leakage during the modeling process to ensure that the evaluation results were reliable.

# Outcome:
The project demonstrates how machine learning can be used to analyze historical startup/business data and build a predictive classification system that estimates the likelihood of startup success.
